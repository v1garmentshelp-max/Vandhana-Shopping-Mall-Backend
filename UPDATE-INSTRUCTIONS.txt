V1 GARMENTS UPDATE

Reward redemption is limited to 10% of the product subtotal after discounts and offers, rounded down to whole points, and capped by the available wallet balance. One point is worth one rupee. A 1000-rupee dress allows up to 100 points; with a 1000-point balance, the customer pays 900 rupees for the dress and keeps 900 points. Delivery and COD charges are paid separately and do not increase the reward limit. A 500-rupee dress allows up to 50 points. Existing points balances, expiry dates and order history are preserved.

Shiwang offer pricing remains 990 for one set, 1599 for two, 2589 for three and 3198 for four, before rewards and delivery charges. The offer ends after 20 October 2026, India time. The maximum reward redemption for these offer totals is 99, 159, 258 and 319 points respectively, subject to the wallet balance.

No database migration or SQL update is required for the 10% redemption limit or the password-reset branding fix.

Deploy the backend first, then rebuild and deploy the website and admin using your existing projects and environment variables. Node.js 24 is the backend runtime.

Backend commands, from the vandhana-backend directory:
npm ci
npm run test:rewards-email
npm run test:mobile
npm run test:commerce
npm run test:offers
npm run preflight:mobile
npm run preflight:commerce

The preflight commands use the existing DATABASE_URL and JWT_SECRET and perform read-only checks. Keep the current production database configuration.

Website commands, from the vandhana-website directory:
npm ci
npm run build

Admin commands, from the vandhana-admin directory:
npm ci
npm run build

Set VITE_API_BASE for the website and REACT_APP_API_BASE for the admin to the same deployed V1 Garments backend origin. The website login and password-reset pages now use VITE_API_BASE, just like checkout. The default origin remains https://vandhana-shopping-mall-backend.vercel.app. Rebuild the frontend after changing its environment variables.

Email configuration on the backend:
SMTP_HOST: your SMTP provider host
SMTP_PORT: 465 for implicit TLS or 587 for STARTTLS
SMTP_USER: the SMTP username for your store
SMTP_PASS: the matching SMTP password or provider credential
FROM_EMAIL: one verified sender email address for V1 Garments
PASSWORD_RESET_SECRET: retain the existing secret

The application sets the outgoing display name to V1 Garments even if FROM_EMAIL contains an old display name. The reset subject and body also use V1 Garments. No production SMTP account or API key was inspected or changed. If the delivered email still shows the old brand, check the provider's verified sender identity and any saved sender contact name in the receiving mailbox. Confirm delivery with a test account after deployment.
